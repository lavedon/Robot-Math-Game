# Kegel Quest pixel font: a 16-bit RPG menu face. 10-pixel lines, baseline under row 7.
# Capitals and digits use rows 1-7 (7 px), lowercase x-height rows 3-7 (5 px), descenders rows 8-9.
# Digits are all 5 wide so numbers line up in columns. 0 is a plain round zero told apart from O by its filled inner
# corners (no dot or slash, so prices like 12,000 stay calm); 1, l and I all differ. The colon sits mid-digit
# (rows 3 and 6) so times like 5:42 read centred.
font pixel
height 10        # line height in pixels
ascent 8         # baseline position (rows 0..7 sit above the baseline)
spacing 1        # extra pixels between glyphs
